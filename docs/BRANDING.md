# Identidade visual

## Arquivos

- `icon.svg`: fonte vetorial do ícone;
- `icon-192.png` e `icon-512.png`: ícones PWA;
- `icon-maskable-*`: versões seguras para recorte no Android;
- `apple-touch-icon.png`: atalho no iOS;
- `og-image.png`: imagem de compartilhamento do aplicativo;
- `docs/assets/easy-train-social-preview.png`: social preview do GitHub;
- `docs/assets/mobile-dashboard.png`: prévia mobile;
- `docs/assets/desktop-editor.png`: editor para computador;
- `docs/assets/social-collabs-competition.png`: recursos sociais.
